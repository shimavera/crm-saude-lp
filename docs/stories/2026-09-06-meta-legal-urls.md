# Story: Corrigir páginas legais para publicação do app Meta

Status: Ready

## Escopo

### Incluído

- Disponibilizar uma página pública de exclusão de dados do SaúdeCRM.
- Usar URLs públicas válidas para privacidade, termos e exclusão de dados no cadastro do app Meta CRM SAÚDE.

### Fora do escopo

- Alterar permissões, integrações ou dados do CRM.
- Enviar a análise do app sem os screencasts e testes exigidos pela Meta.

## Critérios de aceite

- `https://saudecrm.com/privacidade.html` retorna a política de privacidade.
- `https://saudecrm.com/termos.html` retorna os termos de uso.
- `https://saudecrm.com/exclusao-dados.html` informa o procedimento para solicitar exclusão de dados.
- O Meta aceita a URL de privacidade como válida ao publicar o app.
