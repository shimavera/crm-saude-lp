# Arquitetura de front-end

Autor: Juan Lourenço. Versão: 1.0. Data: 29/09/2026.

HTML sem dependências novas, CSS externo assets/futurista.css e JS defer assets/futurista.js. Reutilizar fontes locais. Animação CSS para efeitos constantes, IntersectionObserver para reveal e demonstração, requestAnimationFrame apenas para canvas e pointer tilt. Pausar fora da viewport e em aba oculta. Criar apenas proxy same-origin /api/diagnostic para encaminhar o contrato existente ao destino configurado em LEAD_WEBHOOK_URL e validar confirmação JSON ok true. Preservar demais APIs, blog, materiais e documentos legais. Cabeçalho SEO mantido; schema alinhado ao conteúdo visível.
