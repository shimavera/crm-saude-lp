# Interface demonstrativa do SaúdeCRM

## Controle do documento

Autoria: Juan Lourenço. Versão 1.0, 29/09/2026.
Histórico: criação das três interfaces estáticas para a Story 004.

## Origem e limites

Reconstrução visual em HTML/CSS, orientada pelas referências de interface fornecidas pelo usuário. Não é captura de uma conta real nem execução do código atual do CRM. Não possui conexão com APIs, agenda, atendimento ou banco de dados.

Todos os nomes, mensagens, profissionais, datas de exemplo, indicadores e etapas preenchidas são fictícios. Nenhuma imagem original, fotografia de paciente, telefone, e-mail ou valor financeiro real foi reutilizado. Os valores financeiros demonstrativos são sintéticos; a série do gráfico soma R$ 42.600,00 e o ticket de R$ 5.325,00 corresponde a oito vendas fictícias. O áudio é uma ilustração sem controle de reprodução e sem arquivo de mídia.

As capturas resultantes devem aparecer na LP acompanhadas de: **Interface demonstrativa do SaúdeCRM · dados fictícios**.

## Captura

Servir a raiz do projeto, abrir no navegador com viewport de 1600 × 940 e aguardar as fontes locais.

- `/docs/demo-product/index.html?view=dashboard`
- `/docs/demo-product/index.html?view=conversas`
- `/docs/demo-product/index.html?view=kanban`

Salvar capturas em `assets/product/` com extensão correspondente ao formato real. O build público exclui `docs/`; somente as capturas selecionadas entram na LP. O harness não recebe analytics.
